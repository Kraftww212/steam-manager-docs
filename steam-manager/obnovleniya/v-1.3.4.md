# V 1.3.4

Переделан встроенный браузер аккаунта (антидетект, стабильность), улучшена работа с прокси, изменена разблокировка торговой площадки под новые правила Steam.

### Браузер и расширения

1. Встроенный браузер аккаунта переписан на актуальный движок Electron — раньше страница могла зависнуть на "Loading..." навсегда без единой ошибки в логах; теперь при зависании через 60 секунд показывается страница с ошибкой и кнопкой "Повторить", а временные сетевые сбои (обрыв, таймаут) повторяются автоматически.
2. Профиль браузера аккаунта теперь по-настоящему сохраняется между открытиями (куки сторонних сайтов, история, кэш) — раньше он стирался при каждом закрытии окна.
3. На вкладке расширений появилась кнопка "Проверить обновления" — подтягивает новые версии Steam Inventory Helper, SteamDB и остальных установленных расширений без ручной переустановки. Сама переустановка стала надёжнее: если скачивание оборвётся, рабочая старая версия останется на месте, а не удалится впустую.

### Антидетект и прокси

4. У каждого аккаунта теперь свой стабильный отпечаток браузера (железо, WebGL, canvas/audio, часовой пояс по валюте кошелька) — одинаковый между сессиями одного аккаунта и разный у разных аккаунтов.
5. Закрыта утечка реального IP компьютера через WebRTC в обход HTTP(S)/SOCKS-прокси.

### Разблокировка торговой площадки

6. Steam закрыл покупку предмета из игры, которой аккаунт не владеет — старая связка (Unturned) перестала работать. Функция теперь сначала добавляет игру Zombie Hunter (бесплатно), затем покупает предмет за ~1 цент — разблокировка ТП снова работает под новые правила Steam.

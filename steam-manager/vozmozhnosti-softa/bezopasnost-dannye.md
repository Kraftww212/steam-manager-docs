# Безопасность / данные

**Безопастность вашего аккаунта стоит привыше всего . Для этого реализовано несколько уровней защиты от детекта и кт по цепочке , запомните - любой софт не защищает на 100% от банов , этот процент можно только уменьшить .**

Идентификация устройства:

* Рандомные machine names — каждый аккаунт логинится с уникальным `machineName` (генерируется при первом логине, сохраняется в БД). Steam видит разные «устройства».
* Прокси — каждый аккаунт может работать через свой прокси (SOCKS5/HTTP). Авто-ротация при ошибках. Steam видит разные IP.<br>

Ваши данные храняться у вас на компьютере  -> %appdata%/steam manager.\

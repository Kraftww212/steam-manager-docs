## Страница «Массовые действия»

Центральная страница для выполнения массовых операций одновременно на множестве аккаунтов. Состоит из боковой панели действий (иконки слева), панели настроек действия (центр) и таблицы аккаунтов (справа).

***

#### Боковая панель действий (иконки слева)

Каждая иконка — отдельное массовое действие. Клик переключает центральную панель.

***

### 1. 📄 Экспорт

Выгрузка данных аккаунтов в текстовый файл или maFiles в ZIP-архив.

Возможности:

* Выбор полей для экспорта: Логин, Пароль, Shared Secret, Identity Secret, SteamID, Email, Email-пароль, Prime, Маркет, Refresh Token, Trade URL, Лимитед, VAC бан
* Формат вывода: `txt` с разделителем (например `login:password:email`)
* Экспорт maFiles — для импорта в SDA или другие аутентификаторы

***

### 2. 🎁 Гифт-коды

Активация Wallet-кодов или Gift-кодов на выбранных аккаунтах.

Как работает:

* Вставьте список кодов (по одному на строку)
* Выберите аккаунты справа
* Коды распределяются по аккаунтам и активируются параллельно
* Отчёт: успешно/неуспешно для каждого аккаунта

***

### 3. 🛒 Покупка игры

Покупка игры или подписки по Sub/Package ID на выбранных аккаунтах.

Настройки:

* Тип: Sub (Package) / Bundle / Free Licence
* ID пакета/бандла — числовой ID (например, `34029`)
* Перед покупкой отображается превью: название, изображение, цена, платформы
* Free Packages — внизу отображаются автоматически найденные бесплатные игры/DLC с кнопкой быстрого добавления

***

### 4. 🔓 Покупка Game Item (разблокировка ТП)

Покупка внутриигрового предмета для разблокировки торговой площадки Steam. Требуется для аккаунтов которые никогда не совершали покупок в Steam.

Пресеты:

* Unturned — Cosmetic (по умолчанию, дешёвый вариант)
* TF2 — Mann Co. Supply Crate Key
* TF2 — Командировочный билет
* Можно добавить свой предмет (AppID + ClassID)

***

### 5. 💰 Пополнение

Массовое пополнение баланса Steam-аккаунтов через внешний API.

Настройки:

* API ключ — ключ от сервиса пополнения _**@UndefShop\_bot**_
* Сумма — сумма пополнения на каждый аккаунт
* Результат: transaction\_id или ошибка для каждого аккаунта

***

### 6. 💸 Автопродажа

Массовая продажа marketable-предметов из инвентаря на торговой площадке.

Настройки:

* Игра — выбор инвентаря: CS2, TF2, Dota 2, Rust, Steam
* Стратегия ценообразования — как определяется цена выставления (по минимальной продаже, по стакану и т.д.)
* Выбор аккаунтов → запуск → прогресс по аккаунтам

Отчёт:

* Для каждого аккаунта: сколько продано, сколько ошибок, выручка в $
* Раскрываемый список проданных предметов
* Кнопка «Отчёт» для повторного открытия

***

### 7. 📦 Лутинг

Сбор (слив) инвентаря со всех выбранных аккаунтов на один целевой аккаунт или по Trade URL.

Настройки:

* Игра — CS2, TF2, Steam, Dota 2, Rust
* Цель — целевой аккаунт или Trade URL
* Отправляет все tradable-предметы трейдом

Отчёт:

* Для каждого аккаунта: сколько предметов отправлено, по каким играм
* Количество трейд-офферов
* Успешно/ошибка по каждому аккаунту

***

### 8. 👤 Профиль

Массовое изменение настроек профиля Steam.

Режимы:

* Открыть профиль — сделать профиль публичным
* Закрыть профиль — сделать профиль приватным
* Только друзья — видимость только для друзей
* Закрыть комментарии — отключить комментарии в профиле

***

#### Таблица аккаунтов (правая колонка)

На скриншоте видна таблица со всеми аккаунтами:

* Фильтры: Все / Онлайн / Оффлайн / Ошибка / Группа
* Столбцы: логин, статус, баланс, действия
* Чекбоксы — для выбора аккаунтов которые участвуют в массовом действии
* Статистика вверху: `Всего: 874 · Онлайн: 1 · Помечено: 874 · Выбрано: 0 · Потоки:`&#x20;

### Модальное окно «Инвентарь»

Открывается через правый клик по аккаунту → Инвентарь. Показывает полный инвентарь Steam-аккаунта с возможностью фильтрации, оценки и управления предметами.

***

#### Заголовок

* Инвентарь — \[username] — имя аккаунта
* Инвентарь / Мои лоты — переключение между просмотром инвентаря и выставленных лотов на торговой площадке

#### Вкладки игр

Ряд кнопок для переключения между инвентарями разных игр:

* CS2 — Counter-Strike 2 (выбрано на скрине)
* TF2 — Team Fortress 2
* Steam — инвентарь Steam (карточки, фоны, смайлы, купоны)
* Dota 2 — Dota 2
* Rust — Rust
* \+ — добавить инвентарь другой игры (по AppID/ContextID)

#### Кнопки действий

* Загрузить — загрузить/обновить инвентарь с серверов Steam
* Загрузить цены — запросить текущие цены торговой площадки для всех marketable-предметов. Результат сохраняется в кеш для быстрого доступа
* Сканировать флоаты — запустить массовое сканирование Float Value для скинов CS2 (износ предмета)

#### Информация об обновлении

`Инвентарь обновлён: 21.05.2026 19:56` — когда последний раз загружались предметы `Цены обновлены: 21.04.2026 13:44` — когда последний раз загружались цены

#### Фильтры

* Поиск... — текстовый поиск по названию предмета
* Скрыть not tradable — скрыть предметы которые нельзя обменять
* Скрыть trade ban — скрыть предметы с временной блокировкой обмена
* Стакать ☑ — если включено, одинаковые предметы группируются в стопки (на скрине видно `×29`, `×33`, `×4`, `×2`) с отображением количества в зелёном бейдже. Если выключить — каждый предмет показывается отдельно

#### Сетка предметов

Каждый предмет отображается в виде карточки:

* Иконка — изображение предмета из Steam
* Название — внизу карточки, обрезается если длинное (полное имя видно при наведении)
* Бейджи в углу:
  * T (синий) — предмет tradable (можно обменять)
  * M (синий) — предмет marketable (можно продать на ТП)
  * ×N (зелёный) — количество одинаковых предметов при стакинге

Предметы без бейджей T/M (например, _2019 Service Medal_, _5 Year Veteran Coin_) — не обмениваемые и не продаваемые.

#### Статистика (нижняя строка)

`277 предм. | 266 tradable | 266 marketable | 101 стаков`

* Общее количество предметов
* Сколько из них обмениваемых
* Сколько из них продаваемых
* Количество уникальных стаков (групп одинаковых предметов)

* Уникальных: 10 — количество различных наименований
* Всего: 10 — общее число предметов
* Marketable: 0 — сколько можно продать
* Аккаунтов: 2 — на скольких аккаунтах найдены

#### Фильтры по играм

CS2 (2) / TF2 (2) / Steam (2) / Dota 2 / Rust / Обновить — выбор игр для отображения. Число в скобках — сколько аккаунтов имеют загруженный инвентарь этой игры. Можно выбрать несколько игр одновременно. Кнопка обновления (стрелки) перезагружает данные.

***

#### Переключатели группировки

По предметам / По аккаунтам — два режима отображения:

* По предметам (текущий) — каждая строка = уникальный предмет, показывает сколько штук и на скольких аккаунтах
* По аккаунтам — группировка по аккаунтам, внутри — предметы каждого

***

#### Таблица предметов

Столбцы:

* Чекбокс — выделение предметов для массовых операций (продажа, трейд)
* Предмет — иконка и полное название (Sealed Graffiti | King Me, R8 Revolver | Cobalt Grip и т.д.)
* Кол-во — сколько таких предметов суммарно по всем аккаунтам
* Цена мин — минимальная цена на маркете Steam в выбранной валюте
* Аккаунтов — на скольких аккаунтах лежит этот предмет
* Tradable — сколько из них можно передать в трейде
* Marketable — сколько можно выставить на маркет
* На ТП — сколько уже выставлено на торговую площадку

Поиск... (справа) — фильтрация по названию предмета.

***

#### Советы

* Выделите несколько предметов чекбоксами и используйте иконку монетки для массовой продажи на маркет с выбором стратегии цены
* Сортировка по столбцу Цена мин помогает быстро найти самые дорогие предметы
* Столбец На ТП позволяет отследить, что уже выставлено на продажу и не дублировать

{% tab title="3. Трейд" %}
<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>



Вкладка "Трейд" — массовая отправка предметов между аккаунтами. Позволяет быстро распределить предметы с нескольких аккаунтов на одного получателя или по trade URL.

***

#### Выбор игры

CS2 / TF2 / Steam / Dota 2 / Rust — переключение инвентаря по играм. На скриншоте выбрана TF2 — показываются предметы TF2 со всех аккаунтов.

Обновить (зелёная кнопка) — перезагружает инвентари всех аккаунтов для выбранной игры.

***

#### Фильтры

* Учитывать оффлайн — если включено, показывает предметы и с оффлайн-аккаунтов (из кеша ранее загруженных инвентарей)
* Скрыть в бане — скрывает предметы аккаунтов с trade ban
* Поиск предмета — фильтрация карточек по названию предмета

***

#### Выделение предметов

Выбрать всё видимое / Снять выбор — быстрое выделение/снятие всех предметов.

Выбрано предметов: 0 (всего 0 шт.) — счётчик: сколько уникальных предметов выбрано и сколько штук суммарно.

***

#### Карточки предметов

Каждая карточка показывает:

* Иконка предмета
* Название — Tour of Duty Ticket, Winter 2025 Cosmetic Case
* Чекбокс (левый верхний угол) — для выбора предмета к отправке
* Красное число / серое число — например "22 / 3 акк." означает: 22 штуки на 3 аккаунтах. Или "6 / 4 акк." — 6 штук на 4 аккаунтах

Кликнув на карточку можно задать количество для отправки (сколько штук с каждого аккаунта).

***

#### Нижняя панель — Получатель

На аккаунт / По трейд-URL — два режима отправки:

* На аккаунт (текущий, красная кнопка) — выбираете получателя из списка аккаунтов в базе. Выпадающий список "— выберите получателя —" содержит все аккаунты
* По трейд-URL — вводите trade URL получателя вручную. Полезно для отправки на аккаунт, которого нет в базе

***

#### Кнопка отправки

К отправке: 0 шт. с 0 акк. — счётчик: сколько предметов будет отправлено и с скольких аккаунтов.

Отправить трейд (синяя кнопка) — запускает массовую отправку. Софт создаёт трейд-офферы от каждого аккаунта-отправителя к получателю с выбранными предметами. Прогресс отображается в реальном времени.

***

#### Советы

* Все аккаунты-отправители должны быть онлайн и иметь привязанный identity\_secret для автоматического подтверждения трейдов
* Если у аккаунтов есть trade hold (15 дней) — трейды будут созданы, но предметы дойдут только после окончания холда
* Для лутинга (сбор всех предметов на один аккаунт) удобнее использовать вкладку "Массовые действия" → "Лутинг" — там более продвинутый сценарий с автоматическим подтверждением
* Карточки с большим числом штук (22 / 3 акк.) означают что предмет есть на нескольких аккаунтах — при отправке софт создаст отдельный трейд от каждого
{% endtab %}

{% tab title="4. FloatDB" %}
<figure><img src="../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>



Вкладка "FloatDB" (Premium) — сканирование и аналитика float value скинов CS2 по всем аккаунтам. Позволяет найти редкие скины с уникальным износом и их ранг в мировой базе FloatDB.

***

#### Верхняя строка

Всего: 3911 Items: 3911 — общее количество отсканированных предметов CS2 по всем аккаунтам.

***

#### Фильтры и поиск

Поиск: логин или название... — фильтрация по имени аккаунта или названию скина.

Все (3911) / Items (3911) — переключение режима отображения:

* Все — полный список предметов
* Items — только предметы (без кейсов, граффити и прочего)

FLOAT (выпадающий фильтр) — фильтрация по диапазону float value. Например: только Factory New (0.00–0.07), только Battle-Scarred (0.45–1.00) и т.д.

SEED (выпадающий фильтр) — фильтрация по paint seed. Полезно для поиска редких паттернов (например, Case Hardened с "голубым топом").

***

#### Кнопки действий

Обновить всех — запускает массовое сканирование float value для всех аккаунтов. Проходит по каждому предмету CS2, запрашивает float, seed, paint index и проверяет ранг в базе FloatDB.

Пересканировать — повторное сканирование с принудительным обновлением данных (даже для уже отсканированных предметов).

***

#### Левая панель — Аккаунты

Список всех аккаунтов с количеством отсканированных предметов. Кликом по аккаунту можно отфильтровать таблицу — показать только предметы этого аккаунта:

* Все 3911 — показать все предметы (текущий выбор, подсвечено жёлтым)
* Далее SteamID или логины аккаунтов — клик фильтрует по конкретному аккаунту

***

#### Таблица предметов

Столбцы:

* Чекбокс — выделение для массовых операций (продажа)
* Иконка — превью скина
* Аккаунт — логин аккаунта, на котором лежит предмет
* Скин / Брелок — полное название предмета. Основное название крупным шрифтом (MP5-SD | Lime Hex), под ним дополнительная информация мелким текстом (категория износа — Field-Tested, Battle-Scarred и т.д.)
* Тип — метка "Item" (предмет)
* Float — точное значение float value (например 0.1986033171, 0.1239161553). Чем ближе к 0 — тем лучше состояние
* Seed — paint seed скина (920, 713, 402...). Определяет расположение паттерна на модели
* Pattern — номер паттерна (если применимо)
* Ранг — позиция в мировой базе FloatDB. Сортировка по убыванию (стрелка вниз). Например:
  * 69 — этот скин на 69 месте в мире по float value
  * 275 — на 275 месте
  * 835, 933 — тоже в топ-1000

***

#### Советы

* Предметы в топ-1000 мира по float value могут стоить значительно дороже рыночной цены — коллекционеры платят премию за редкий износ
* Ранг обновляется из базы FloatDB — если скин только появился на аккаунте, нужно пересканировать
* Колонка Seed полезна для Case Hardened, Fade и других скинов, где паттерн влияет на цену (например, seed 661 = "голубой топ" для AK-47 Case Hardened)
* Выделите ценные предметы чекбоксами для массовой продажи прямо отсюда
* Сканирование больших количеств может занять время — прогресс отображается в реальном времени
{% endtab %}

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>



Вкладка "Хранилища" (Premium) — управление Storage Units CS2 (контейнерами для хранения предметов). Позволяет просматривать содержимое, депозитить и выводить предметы через Game Coordinator.

***

#### Строки аккаунтов

Каждая строка — аккаунт из базы. Для работы с хранилищами нужно подключение к Game Coordinator CS2.

Справа кнопка "Подключить GC" (синяя) — подключает аккаунт к Game Coordinator CS2.&#x20;

* GC подключен (зелёная метка) — Game Coordinator активен
* 2 хранилища — у аккаунта найдено 2 Storage Unit
* Обновить — перезагрузить список хранилищ и их содержимое
* Отключить — разорвать соединение с GC
* Paris 2023 — название хранилища (можно переименовывать). Показывает 382/1000 предметов — заполнено 382 из максимальных 1000 слотов
* Casert — второе хранилище. 0/1000 предметов — пустое

Клик по хранилищу открывает модальное окно управления содержимым (скриншот 2).

***

<figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

Paris 2023 (382/1000) — аккаунт, название хранилища и заполненность.

Группировка (чекбокс) — если включить, одинаковые предметы группируются в одну строку с указанием количества.

Закрыть — закрыть модальное окно.

***

#### Левая колонка — Инвентарь&#x20;

Предметы, которые лежат в инвентаре аккаунта (не в хранилище).

Поиск... — фильтрация по названию.

Все — кнопка показать все предметы (сброс фильтра).

Список предметов с иконками и описанием.

***

#### Центральные кнопки

→ (стрелка вправо) — депозит: переместить выбранные предметы из инвентаря в хранилище.

← (стрелка влево) — вывод: переместить выбранные предметы из хранилища обратно в инвентарь.

Обновить — перезагрузить содержимое обоих списков.

***

#### Правая колонка — Хранилище&#x20;

Предметы, которые лежат внутри Storage Unit.&#x20;

Поиск... — фильтрация по названию.

Все — сброс фильтра.

***

#### Как пользоваться

1. Подключите GC — нажмите "Подключить GC" у нужного аккаунта (аккаунт должен быть онлайн)
2. Откройте хранилище — кликните по названию&#x20;
3. Депозит: выберите предметы слева (инвентарь) → нажмите стрелку →
4. Вывод: выберите предметы справа (хранилище) → нажмите стрелку ←

***

#### Советы

* Storage Unit вмещает максимум 1000 предметов — счётчик в заголовке показывает текущую заполненность
* Операции депозита/вывода выполняются по одному предмету через GC — при большом количестве это может занять время. Прогресс отображается в реальном времени
* Переименование хранилища — ПКМ по названию или через отдельную кнопку
* Хранилища полезны для долгосрочного хранения инвестиционных скинов/наклеек — предметы внутри не занимают слоты основного инвентаря
* Если GC не подключается — убедитесь что аккаунт онлайн и CS2 не запущена на этом аккаунте в другом месте

{% tab title="6. Крафт" %}
<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>



Это окно позволяет крафтить скины CS2 через контракты обмена (Trade Up Contract). Предметы одного качества (10 штук) можно обменять на 1 предмет следующего по рарности уровня.

***

Верхняя панель:

* Крафт CS2 — имя аккаунта и заголовок окна.
* Группировка (чекбокс справа) — включает/выключает группировку предметов по качеству (рарности).
* Закрыть — закрывает окно крафта.

***

Вкладки качества (рарности):

* Промышленное (Uncommon) &#x20;
* Ширпотреб (Common)&#x20;
* Армейское (Rare) &#x20;

Крафт работает внутри одного уровня: выбираешь 10 предметов одного качества → получаешь 1 предмет следующего.

***

Фильтры и выбор:

* Поиск — текстовый фильтр по названию.
* Все — выбрать все предметы на текущей вкладке.
* Снять — снять выделение со всех.
* 0 выбрано ≈ $0.00 — количество выбранных предметов и их суммарная стоимость.

***

Таблица предметов:

Каждая строка содержит:

* Чекбокс — для выбора предмета в крафт.
* Иконка — миниатюра скина.
* Название — полное название (оружие, скин, состояние износа).
* Тип — категория оружия (Industrial Grade Sniper Rifle, Pistol, SMG и т.д.).
* Цена — рыночная цена. Зелёным цветом.
* Кол. — количество одинаковых предметов (x1, x2...).

***

Панель "Крафт" (справа):

Панель покупки предметов с торговой площадки Steam. Открывается из бокового меню или через поиск предмета. Состоит из двух вкладок: Поиск и Избранное.

#### Вкладка «Поиск»&#x20;

**Строка поиска**

* Вставьте ссылку на предмет с торговой площадки Steam (формат `https://steamcommunity.com/market/listings/...`) и нажмите Найти
* Софт автоматически определяет игру, название предмета и загружает книгу ордеров (orderbook)

**Карточка предмета**

После поиска отображается:

* Иконка предмета — изображение с торговой площадки
* Название — полное имя предмета (например, _Mann Co. Supply Crate Key_)
* ★ — кнопка добавления в избранное (сохраняет предмет для быстрого доступа)
* Мин. продажа — самая низкая цена продавца (зелёным, `107 UAH`)
* Макс. покупка — самая высокая цена покупателя (зелёным, `107 UAH`)

**Таблица ордеров**

Две колонки:

* Продавцы (слева, зелёный заголовок) — цены и количество предметов на продажу, отсортированы от самой низкой. Например: `107 UAH — 174 шт.`, `108 UAH — 587 шт.`
* Покупатели (справа, оранжевый заголовок) — цены и количество ордеров на покупку, отсортированы от самой высокой. Например: `107 UAH — 91 шт.`, `106 UAH — 3495 шт.`

Таблица позволяет оценить глубину рынка и выбрать оптимальную цену.

**Панель создания ордера (правая колонка)**

* Цена за шт. — поле ввода цены в выбранной валюте (отображается в `UAH` на скрине)
* Кол-во — количество предметов для покупки
* Быстрые кнопки цены:
  * _Макс. покупка_ — устанавливает цену равную максимальной цене покупателя
  * _Мин. продажа_ — устанавливает цену равную минимальной цене продавца
* Режимы покупки:
  * _Фикс. кол-во_ — купить указанное количество по указанной цене
  * _На весь баланс_ — потратить весь баланс выбранных аккаунтов на покупку по указанной цене (автоматически рассчитает максимальное количество)
* Аккаунты — список онлайн-аккаунтов сгруппированных по валюте, с отображением баланса. Отметьте чекбоксами аккаунты которые будут участвовать в покупке. _Выбрать все_ — отметить все сразу
* потоков — количество параллельных потоков для создания ордеров
* Создать ордер — запускает массовую покупку на всех выбранных аккаунтах

**Выбор валюты**

В правом верхнем углу — выпадающий список `UAH` для выбора валюты отображения цен. Показывает только валюты онлайн-аккаунтов. При смене валюты книга ордеров перезагружается с аккаунта соответствующей валюты.

**Лог**

Внизу панели — сворачиваемый лог операций с подробной информацией: какой предмет найден, параметры orderbook и т.д. Кнопка Очистить удаляет записи.

#### Вкладка «Избранное»&#x20;

Сохранённые предметы для быстрого доступа:

* Список всех добавленных в избранное предметов с иконкой и названием
* Клик по предмету загружает его orderbook и заполняет панель создания ордера
* × — удалить предмет из избранного
* Панель создания ордера справа работает так же, как на вкладке "Поиск"

Избранное удобно для предметов которые вы покупаете регулярно — не нужно каждый раз вставлять ссылку.

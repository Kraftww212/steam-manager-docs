# Вкладка "Инвентарь"

<figure><img src="../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

Страница "Инвентарь" — основной раздел для работы с предметами всех аккаунтов. Объединяет инвентари, торговлю, аналитику и массовые операции.

### Модальное окно «Инвентарь»

Показывает полный инвентарь Steam-аккаунта с фильтрацией, оценкой и управлением предметами.

* Вкладки Инвентарь / Сеты / Мои лоты
* Вкладки игр: CS2 / TF2 / Steam / Dota 2 / Rust / + (кастомная по AppID/ContextID)
* Кнопки: Загрузить (инвентарь с серверов Steam), Загрузить цены (текущие цены маркета в кеш), Сканировать флоаты (Float Value для CS2)
* Дата последнего обновления инвентаря и цен
* Фильтры: поиск, скрыть not tradable, скрыть trade ban, стакать (одинаковые предметы группируются, `×N` в зелёном бейдже)

Каждый предмет — карточка с иконкой, названием и бейджами: T (tradable), M (marketable), ×N (количество при стакинге). Предметы без T/M не обмениваются и не продаются.

Нижняя строка: `277 предм. | 266 tradable | 266 marketable | 101 стаков`.
{% endtab %}

{% tab title="2. Все предметы" %}
<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

Агрегированный просмотр предметов по всем аккаунтам. Каждая строка — уникальный предмет: количество, цена, на скольких аккаунтах лежит, статусы.

Верхние карточки: всего предметов, marketable, общая стоимость, аккаунтов, уникальных.

Фильтры (левая панель): скрыть нетрейдабельные, скрыть немаркетабельные, скрыть выставленные на ТП, учитывать оффлайн, по валютам. Валюта цен — выпадающий список.

{% hint style="info" %}
Поиск на этой вкладке фильтрует только «Все предметы». Вкладки Трейд, FloatDB и Сеты видят все аккаунты по групповому фильтру — набранный тут текст на них не влияет.
{% endhint %}

Фильтры по играм: CS2 (2) / TF2 (2) / Steam (2) / Dota 2 / Rust. Число в скобках — сколько аккаунтов имеют загруженный инвентарь этой игры.

Режимы: По предметам (строка = предмет) / По аккаунтам (группировка по аккаунтам).

Столбцы таблицы: чекбокс, Предмет, Кол-во, Цена мин, Аккаунтов, Tradable, Marketable, На ТП.

Массовые операции: выделите предметы чекбоксами и через иконку монетки — продажа на маркет (с выбором стратегии цены), снятие с продажи, трейд. В продажу и трейд уходят только реально пригодные экземпляры: неторгуемые и уже выставленные на ТП не отправляются.
{% endtab %}

{% tab title="3. Трейд" %}
<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

Массовая отправка предметов между аккаунтами: быстро распределить предметы с нескольких аккаунтов на одного получателя или по trade URL.

* Выбор игры: CS2 / TF2 / Steam / Dota 2 / Rust, кнопка Обновить перезагружает инвентари
* Фильтры: учитывать оффлайн, скрыть в бане, поиск предмета
* Выделение: Выбрать всё видимое / Снять выбор, счётчик выбранных
* Карточки: иконка, название, чекбокс, «22 / 3 акк.» (22 штуки на 3 аккаунтах). Клик по карточке задаёт количество для отправки с каждого аккаунта — в план идут только торгуемые, не выставленные на ТП экземпляры
* Получатель: На аккаунт (выбор из списка) или По трейд-URL. Отправка доступна только когда получатель онлайн
* Отправить трейд — создаёт офферы от каждого отправителя. Большие партии автоматически режутся по 200 предметов на оффер

Советы: отправители должны быть онлайн с `identity_secret`; при trade hold предметы дойдут после холда; для слива всего инвентаря на один аккаунт удобнее «Массовые действия → Лутинг».
{% endtab %}

{% tab title="4. FloatDB" %}
<figure><img src="../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

(Premium) Сканирование и аналитика float value скинов CS2 по всем аккаунтам: находит редкие скины и их ранг в мировой базе FloatDB.

* Фильтры: поиск по логину/названию, FLOAT (диапазон износа), SEED (paint seed)
* Кнопки: Обновить всех (сканирование float/seed/paint index и ранга), Пересканировать (принудительно)
* Левая панель — аккаунты с количеством отсканированных предметов, клик фильтрует таблицу
* Столбцы: чекбокс, иконка, Аккаунт, Скин, Тип, Float, Seed, Pattern, Ранг

Сканирование не стирает уже загруженный инвентарь при обрыве связи. Ценные предметы можно выделить и продать прямо отсюда.
{% endtab %}

{% tab title="5. Хранилища" %}
<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

(Premium) Управление Storage Units CS2 через Game Coordinator.

* Кнопка «Подключить GC» у аккаунта (аккаунт должен быть онлайн, CS2 не запущена в другом месте)
* Список хранилищ, заполненность (например, 382/1000), переименование
* Клик по хранилищу — модалка: слева инвентарь, справа хранилище, между ними стрелки → (депозит) и ← (вывод)

<figure><img src="../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

При выводе предметы доступны, даже если их нет в последнем веб-снимке инвентаря. Операции идут по одному предмету через GC — при больших объёмах это занимает время.
{% endtab %}

{% tab title="6. Крафт" %}
<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

Крафт скинов CS2 через контракты обмена (Trade Up): 10 предметов одного качества → 1 предмет следующего уровня.

* Вкладки качества (рарности): Ширпотреб, Промышленное, Армейское и т.д.
* Фильтры: поиск, Все, Снять, счётчик выбранных и стоимость
* Таблица: чекбокс, иконка, название, тип, цена, количество
* Панель справа: Выбрано, Батчей (по 10), К крафту, кнопка «Крафтить N», Обновить инвентарь

Софт сам разбивает выбранные предметы на батчи по 10 и разделяет StatTrak и обычные (Steam не даёт смешивать их в одном контракте). Счётчик считает только реально видимые и выбранные предметы. После крафта нажмите «Обновить инвентарь».
{% endtab %}

{% tab title="7. Сеты" %}
<figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>

Управление коллекционными карточками Steam: сборка полных сетов, кросс-аккаунт обмен, крафт значков.

* Загрузить сеты — карты со всех онлайн-аккаунтов + парсинг бейджей
* Фильтры: Все / Полные / Кросс
* Цель: Аккаунт / Trade URL — куда отправлять карты
* Автокрафт — после отправки автоматически крафтит значок (ждёт приёма трейда, до 3 попыток)
* Таблица игр (Карт, В сете, Полных, Кросс) и панель деталей с сеткой карт (недостающие показаны красным `?`)
* Массовая отправка: количество сетов на игру и «Собрать и отправить» (потоки из настроек)
{% endtab %}

#### Кнопки действий страницы

* Выбор игры: CS2 / TF2 / Steam / Dota 2 / Rust / +
* Загрузить CS2 (N) — массовая загрузка инвентаря выбранной игры для всех онлайн-аккаунтов (N — сколько онлайн)
* Покупка — открывает панель покупки на маркете (BuyPanel)
* Колонки — настройка видимых столбцов
* Поиск по логину

***

### Панель покупки (BuyPanel)

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

Покупка предметов через Buy Orders. Две вкладки: Поиск и Избранное.

**Поиск:** вставьте ссылку на предмет с маркета и нажмите Найти — софт определит игру и название, загрузит стакан ордеров. Карточка показывает иконку, название, ★ (в избранное), мин. продажу и макс. покупку.

**Таблица ордеров:** Продавцы (слева) и Покупатели (справа) с ценами и количеством — глубина рынка.

**Создание ордера (справа):** цена за штуку, количество, быстрые кнопки «Макс. покупка» / «Мин. продажа», режимы «Фикс. кол-во» и «На весь баланс», список аккаунтов по валюте с балансами, потоки, «Создать ордер». Цена конвертируется в валюту каждого аккаунта корректно — смена валюты пересчитывает ордер.

**Валюта** (правый верх) — выбор валюты отображения (только валюты онлайн-аккаунтов). **Избранное** — сохранённые предметы для быстрого доступа.

***

#### Советы

* Массовая загрузка загружает инвентарь только у онлайн-аккаунтов.
* Стоим. инв. обновляется при загрузке цен — если 0 или устарело, откройте инвентарь и нажмите «Загрузить цены».
* Контекстное меню (ПКМ) доступно и тут — те же действия, что на странице Аккаунты.

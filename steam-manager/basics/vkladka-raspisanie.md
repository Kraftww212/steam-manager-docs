# Вкладка "Расписание"

<figure><img src="../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>

## Страница «Расписание»

Планировщик автоматических задач для прогрева аккаунтов — имитация активности живого пользователя Steam по расписанию.

***

#### Панель инструментов (правый верх)

Три кнопки:

* Обновить — перезагрузить список задач из базы данных (если задачи были изменены или создались внешне)
* 💡 Рекомендации — открывает панель готовых шаблонов задач (подробнее ниже)
* \+ Новая задача — создать задачу с нуля через модальное окно

***

### Карточка задачи

Каждая задача отображается как блок с информацией:

* Переключатель (синий) — вкл/выкл задачу. Выключенная задача не запускается по расписанию
* Название — например, "Новая задача"; рядом появляется метка ⏳ выполняется, пока задача идёт
* Шаги — список действий, которые будут выполнены последовательно (например, `1. Idle в игре (заданное время)`)
* Расписание — когда задача запускается (`каждый день в 09:00`)
* Следующий — дата и время следующего запуска (зелёным, `22.06, 09:00`)
* Последний — время и результат прошлого запуска (✓ или ✗ с текстом ошибки, при частичных ошибках — «Частично»)
* Кнопки управления:
  * ▶ Запустить — запустить задачу вручную прямо сейчас, не дожидаясь расписания. Работает и для выключенных задач, плановый запуск при этом не сдвигается
  * Изменить — открыть модальное окно редактирования (шаги, расписание, параметры). Переименование не сбивает таймер и не перевыбирает случайный день
  * История — журнал прошлых запусков: когда, сколько длился, результат по каждому шагу (`3/5 ок` и первые ошибки)
  * Удалить (красная) — удалить задачу

***

### Типы расписания

| Тип                   | Описание                                                                           |
| --------------------- | ---------------------------------------------------------------------------------- |
| Ежедневно             | Каждый день в указанное время (например, `09:00`)                                  |
| Таймер                | Каждые N минут (например, каждые 120 минут)                                        |
| Дни недели            | Конкретные дни + время (например, Пн, Ср, Пт в 10:00)                              |
| Случайно раз в неделю | Один случайный запуск в неделю в заданном временном окне (например, `09:00-22:00`) |

Точность запуска — полминуты. Если приложение было выключено или ПК спал и запуск пропущен больше чем на 10 минут, задача **не** стартует пачкой при включении, а переносится на следующий слот по расписанию. Одна и та же задача никогда не запускается параллельно сама с собой, даже если её шаг длится часами.

***

### Параметры задачи

* Потоки — сколько аккаунтов обрабатывать одновременно (по умолчанию из настроек), плавный старт потоков через заданный интервал
* Пропускать играющих — не трогать аккаунты, на которых прямо сейчас играют с другого устройства
* Ретраи при ошибке шага и «остановить цепочку при ошибке»
* Пауза между шагами — случайная, в заданном диапазоне секунд
* Авто-вход перед цепочкой и авто-выход после. Выходят только те аккаунты, которые планировщик сам залогинил: аккаунты, которые вы держали онлайн, не трогаются
* Аудитория — все аккаунты или конкретные (в шагах можно задать свой список аккаунтов)

***

### Доступные действия (шаги задачи)

Каждая задача состоит из цепочки шагов. Доступные действия:

Безопасные просмотры (только чтение — не оставляют следов):

| Действие                       | Что делает                                                                      |
| ------------------------------ | ------------------------------------------------------------------------------- |
| Магазин                        | Заходит на страницы случайных игр в Steam Store                                 |
| Рекомендации (Discovery Queue) | Прокликивает очередь рекомендаций Steam (засчитывается как ежедневное действие) |
| Хаб игры                       | Посещает Community Hub случайной игры из библиотеки                             |
| Инвентарь (свой)               | Открывает свой инвентарь                                                        |
| Свой профиль                   | Заходит на свою страницу профиля                                                |
| Друзья                         | Заходит в ленту друзей, посещает профили                                        |
| Маркет (главная)               | Открывает главную торговой площадки                                             |
| Уведомления                    | Проверяет уведомления                                                           |
| Значки / ачивки                | Посещает страницу значков                                                       |
| Мастерская игры                | Просмотр мастерской                                                             |

Idle:

| Действие    | Что делает                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------ |
| Idle в игре | Запускает игру на заданное время (накрутка часов). Можно указать конкретную игру или случайную из библиотеки |

Активные (пишут на аккаунт — создают видимую активность):

| Действие            | Что делает                            |
| ------------------- | ------------------------------------- |
| Лайк скриншота      | Ставит лайк случайному скриншоту      |
| Комментарий         | Оставляет комментарий в профиле друга (встроенный пул фраз или свои, каждая с новой строки) |
| Лайк/избранное гайд | Добавляет гайд в избранное            |
| Добавить в вишлист  | Добавляет игру в список желаемого     |
| Вступить в группу   | Вступает в Steam-группу (свои URL через запятую или с новой строки) |

***

### 💡 Рекомендации (готовые шаблоны)

Кнопка «Рекомендации» открывает библиотеку готовых цепочек:

🟢 Лёгкий прогрев Максимально тихий: заходим, идлим игру \~20 минут, листаем магазин и инвентарь, выходим. Без write-операций — идеально для свежих аккаунтов.

🟡 Имитация активности Прокликиваем страницы как живой юзер: лента рекомендаций, друзья, хаб, значки. Discovery Queue засчитывается Steam как ежедневное действие.

🔥 Полный прогрев Всё: просмотры, idle, комменты, лайки, вишлист. Максимально похоже на живого человека. Рекомендуется 1-2 раза в неделю.

⏱️ Только накрутка часов Заходим, сидим в игре 1-2 часа, выходим. Для накрутки playtime в конкретной игре (по умолчанию CS2).

При выборе шаблона — он подставляется в форму создания задачи с рекомендуемым расписанием, можно доредактировать. Свои цепочки тоже можно сохранять как шаблоны (со расписанием и параметрами или только шаги) и применять к новым задачам.

# Вкладка "Аккаунты"

## &#x20;1. Главная страничка

<figure><img src="../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>

1\. Войти во все — массовый логин всех аккаунтов в базе. Запускает параллельный вход (количество потоков настраивается в Настройках). Аккаунты авторизуются в Steam, получают куки сессии и становятся доступны для всех операций.

2\. Выйти из всех — массовый логаут всех онлайн-аккаунтов. Закрывает сессии Steam.

3\. Стоп (красная кнопка) — экстренная остановка всех текущих операций: логинов, продаж, покупок, CL-заданий и других массовых действий.

4\. Импорт — загрузка аккаунтов в базу. Поддерживает: TXT-файл (формат login:password:shared\_secret и др. варианты), maFile-файлы (Steam Guard), а также привязку maFiles из папки к уже существующим аккаунтам.

<figure><img src="../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>

5\. Добавить — ручное добавление одного аккаунта: ввод логина, пароля, shared\_secret и других данных.

6\. Группы  — управление группами аккаунтов. Можно создавать именованные группы с цветными метками, добавлять/удалять аккаунты из групп. Число в скобках — количество групп. Используется для фильтрации и массовых действий над выбранной группой.

7\. Колонки — настройка видимых столбцов таблицы. Можно скрыть/показать: номер, аватар, логин, статус, баланс, холд, стоимость CS2 инвентаря, лог, 2FA, прокси и другие колонки. Позволяет адаптировать таблицу под свои нужды.

8\. Обновить (иконка обновления) — запускает refresh info для выбранных или всех аккаунтов: обновляет баланс, статус кошелька, флаги аккаунта и другие данные с серверов Steam.

9\. Баг фича&#x20;

10\. Статистика в шапке — "Онлайн: 2, Пул: 0/0, Всего: 973". Быстрый обзор: сколько аккаунтов онлайн, состояние пула параллельных сессий, общее количество.

11\. Поиск по логину — фильтрация таблицы по имени аккаунта. Поддерживает частичный поиск — начните вводить логин и таблица отфильтруется мгновенно.

12\. Таблица аккаунтов — основная область. Столбцы:

* \# — порядковый номер в БД (перетаскивание строк меняет порядок)
* Аватар — иконка Steam-профиля
* Логин — имя аккаунта (маскируется звёздочками, если включено в Настройках)
* Статус — текущее состояние: Оффлайн / Онлайн / Ошибка
* Баланс — баланс кошелька Steam в валюте аккаунта
* Холд — холд баланс ( если есть )&#x20;
* CS2 Инв. — стоимость CS2 инвентаря
* Лог — последнее событие аккаунта (например "Web session established")
* 2FA — наличие привязанного Steam Guard (+ = привязан)
* Прокси — назначенный прокси-сервер

***

### 2.  Контекстное меню (ПКМ по строке)

открывает расширенное меню: логин/логаут, редактирование, открыть инвентарь, запустить чекер, CL-прогресс, мобильные подтверждения, трейды, встроенный браузер Steam, копирование данных (login:pass, SteamID, 2FA-код, shared\_secret и др.), логи, создание команды, удаление.

<figure><img src="../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>

_Выйти_ — разлогинивает выбранный аккаунт из Steam-сессии. Статус меняется на "Оффлайн". Если аккаунт уже оффлайн — пункт будет "Войти".

_Редактировать_ — открывает модальное окно с полями аккаунта: логин, пароль, shared\_secret, identity\_secret, прокси, заметки и другие параметры. Здесь же можно добавить maFile или изменить данные авторизации.

***

### 2.1 Инвентарь&#x20;

открывает модальное окно с полным инвентарём аккаунта. Показывает предметы по играм (CS2, TF2, Steam, Dota 2 и др.), их рыночную стоимость. Отсюда можно продать предметы на маркет или выбрать для трейда.

<figure><img src="../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

Модальное окно "Инвентарь" — открывается через ПКМ по аккаунту → "Инвентарь". Показывает полное содержимое Steam-инвентаря конкретного аккаунта.

Инвентарь — заголовок с логином аккаунта, чей инвентарь открыт.

Вкладки справа: Инвентарь / Сеты / Мои лоты — переключение между режимами:

* Инвентарь — предметы в инвентаре аккаунта (текущий вид)
* Сеты — наборы карточек Steam (для крафта значков): показывает полные и неполные сеты, позволяет отправить карточки между аккаунтами
* Мои лоты — предметы, выставленные на продажу на маркете. Отсюда можно снять лоты или перевыставить по новой цене

#### Выбор игры

CS2 / TF2 / Steam / Dota 2 / Rust / + — переключение инвентаря по играм. Кнопка "+" позволяет добавить кастомную игру по App ID и Context ID (для игр, которых нет в стандартном списке).

#### Кнопки действий

Загрузить (зелёная) — загружает инвентарь выбранной игры с серверов Steam. Обновляет список предметов.

Загрузить цены — запрашивает текущие рыночные цены для всех предметов в инвентаре с маркета Steam.&#x20;

Сканировать флоаты — сканирует float value (износ) для скинов CS2. Показывает точное значение износа каждого предмета и проверяет ранг в базе FloatDB (топ-1000).

#### Фильтры

Поиск  — фильтрация предметов по названию.

Скрыть not tradable — скрывает предметы, которые нельзя передать в трейде (trade lock, не обмениваемые).

Скрыть trade ban — скрывает предметы с временным trade ban (ожидание 7 дней после покупки на маркете и т.д.).

Стакать — группирует одинаковые предметы в одну карточку с указанием количества, вместо отображения каждого по отдельности.

***

### 2.2 Чекер

<figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

запускает полную проверку аккаунта: баланс кошелька, список лицензий/игр, VAC/Trade баны, статус Steam Guard, ограничения маркета и другую информацию. Результат показывается в модальном окне.

Чекер — имя проверяемого аккаунта.

* Обновлено — дата и время последней проверки
* Ukraine — страна аккаунта (определяется по кошельку)
* SteamID — уникальный Steam ID64 аккаунта&#x20;

***

#### Кошелёк

Баланс: 16.84 UAH — текущий доступный баланс кошелька Steam в валюте аккаунта.

В холде: 0.00 UAH — средства, которые заморожены.

***

#### Ограничения

Блок показывает статусы банов и ограничений аккаунта. Зелёная рамка = всё чисто, красная = есть проблема:

* VAC: false — нет бана Valve Anti-Cheat. Если true — аккаунт забанен в играх с VAC
* Community Ban: false — нет бана в Steam Community. Если true — ограничен доступ к профилю, форумам, комментариям
* Locked: false — аккаунт не заблокирован. Если true — аккаунт заморожен Steam&#x20;
* Limited: false — аккаунт не ограничен. Limited аккаунты не могут добавлять друзей, торговать и использовать маркет (нужна покупка от $5)
* Trade Ban: false — нет бана на трейды. Если true — аккаунт не может отправлять и получать обмены
* Маркет: true (зелёная рамка) — доступ к торговой площадке Steam открыт. Если false — маркет недоступен (ограничения, холд, или не выполнены условия)

***

#### Стоимость инвентаря

Чекбоксы: CS2 / Dota 2 / Rust / Steam — выбор игр, инвентарь которых нужно оценить. Можно отметить любую комбинацию.

Оценить инвентарь (зелёная кнопка) — запускает загрузку инвентаря по выбранным играм и расчёт рыночной стоимости каждого предмета по ценам маркета Steam. Результат покажет суммарную стоимость в USD.

***

#### Игры / Лицензии&#x20;

Игры  — количество игр в библиотеке аккаунта. Лицензии  — общее количество лицензий (включает DLC, серверные лицензии и т.д. — может быть больше, чем игр).

Поиск по названию или appid... — фильтр списка игр. Можно ввести название или числовой App ID.

Таблица игр — список всех игр аккаунта:

* App ID (слева) — уникальный числовой идентификатор игры в Steam (440, 480, 570, 730 и т.д.)
* Название — Team Fortress 2, Spacewar, Dota 2, Counter-Strike 2, POSTAL, We Are The Dwarves, Cyberpunk SFX
* Тип (справа) — "game" / "Game" — категория лицензии

***

### 2.3 CL прогресс

<figure><img src="../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

Модальное окно "Community Leader" — открывается через ПКМ по аккаунту → "CL прогресс". Показывает прогресс выполнения заданий значка Community Leader для конкретного аккаунта.

***

Community Leader  — аккаунт, для которого показан прогресс.

Выполнить все — запускает автоматическое последовательное выполнение всех незавершённых заданий (со статусом "Todo"). Софт сам пройдёт по каждому невыполненному квесту и попробует его закрыть.

Обновить — загружает актуальный прогресс с серверов Steam. Проверяет, какие задания были выполнены вручную или через другие инструменты.

***

#### Прогресс

85% — 23 / 27 выполнено — круговая диаграмма и счётчик. 23 из 27 заданий пройдены, осталось 5 заданий.

***

#### Список заданий

Каждая строка — одно задание значка CL. Зелёная галочка и "Done" = выполнено, жёлтый текст "Todo" = ещё не пройдено.

***

Debug: Steam API response — кнопка для просмотра сырого ответа Steam API. Полезно для диагностики, если какое-то задание не засчитывается.

***

### 2.4 Подтверждения действий в стиме&#x20;

Модальное окно "Подтверждения" — открывается через ПКМ по аккаунту → "Подтверждения". Аналог мобильного приложения Steam Guard — показывает все ожидающие мобильные подтверждения.

***

Подтверждения — логин аккаунта, для которого запрошены подтверждения.

Обновить — повторно запрашивает список подтверждений с серверов Steam. Полезно если вы только что выставили предмет на маркет или отправили трейд.

***

Когда подтверждения есть, здесь отображается список с типами:

* Продажа на маркете — подтверждение выставления предмета на торговую площадку
* Трейд — подтверждение отправки обмена другому игроку
* Покупка на маркете — подтверждение ордера на покупку

Для каждого подтверждения доступны кнопки:

* Принять — подтвердить операцию (аналог "Подтвердить" в мобильном приложении Steam)
* Отклонить — отменить операцию
* Принять все — массовое подтверждение всех ожидающих операций одной кнопкой

***

#### Важно

* Для работы подтверждений у аккаунта должен быть привязан identity\_secret (из maFile). Без него софт не может генерировать коды подтверждения
* При массовой продаже софт может автоматически подтверждать операции — для этого используется кнопка "Подтвердить всё" на странице маркета или в контекстном меню

***

### 2.5 Трейд-офферы

Модальное окно "Трейд-офферы" — открывается через ПКМ по аккаунту → "Трейд-офферы". Показывает все обмены предметами для конкретного аккаунта.

***

Трейд-офферы — логин аккаунта.

Обновить — загружает актуальный список трейдов с серверов Steam.

Закрыть — закрывает окно.

***

#### Вкладки

Входящие  — трейды, которые другие игроки отправили этому аккаунту. Первое число — активные офферы, второе — общее количество. Для каждого входящего оффера доступны действия:

* Принять — подтвердить обмен и получить предметы
* Отклонить — отказаться от обмена

Исходящие  — трейды, которые этот аккаунт отправил другим. Для исходящих доступно:

* Отменить — отозвать отправленный оффер

***

#### Содержимое

Нет исходящих офферов — аккаунт не отправлял обменов, которые ожидают ответа.

Когда офферы есть, для каждого отображается:

* Имя второго участника обмена
* Предметы, которые отдаёте и получаете
* Статус оффера (ожидает, на удержании, истёк)
* Кнопки действий

***

### 2.6 Встроенный браузер

Кнопка "Открыть браузер" — доступна через ПКМ по аккаунту → "Открыть браузер". Запускает встроенный Chromium-браузер с автоматически авторизованной сессией выбранного Steam-аккаунта.

***

#### Что это

Полноценный веб-браузер прямо внутри Steam Manager. При открытии в него автоматически подставляются куки текущей сессии аккаунта — вы сразу залогинены в Steam Community и Steam Store без ввода логина/пароля/2FA.

`Любые действия — всё то же самое, что и в обычном браузере, но вы уже авторизованы`

Браузер построен на Electron BrowserWindow (движок Chromium). При открытии софт:

1. Берёт куки активной сессии аккаунта (cookieString)
2. Устанавливает их в отдельное окно браузера
3. Открывает Steam Community по умолчанию (или указанный URL)
4. Поддерживает установленные расширения (Extensions)&#x20;

***

#### Советы для браузера

* Браузер работает только для онлайн-аккаунтов — если аккаунт оффлайн, сессии нет и браузер не сможет авторизоваться
* Каждый браузер открывается в отдельном окне — можно открыть несколько аккаунтов параллельно
* Расширения Chromium (установленные через вкладку "Настройки" → Расширения) доступны и в этом браузере
* Если сессия истекла — закройте браузер, перелогиньте аккаунт и откройте заново



_Обновить инфо_ — обновляет данные аккаунта с серверов Steam: баланс, статус кошелька, флаги, аватар. Не требует полного перелогина.

_Данные (подменю со стрелкой)_ — раскрывает дополнительное подменю для быстрого копирования в буфер обмена:

* login:password
* SteamID64
* Текущий 2FA-код
* shared\_secret
* identity\_secret
* Trade URL
* Куки сессии
* И другие поля аккаунта

_Логи_ — открывает модальное окно с полной историей событий аккаунта: логины, ошибки, продажи, покупки, CL-задания и другие действия с временными метками.

_Создать команду_ — создаёт пользовательскую команду на основе данных аккаунта. Команды — это сохранённые действия, которые можно повторно запускать.

## Полезные советы

* Перетаскивание строк — зажмите строку и перетащите для изменения порядка аккаунтов в списке.
* Двойной клик по строке — открывает модальное окно редактирования аккаунта.
* Фильтр "Все аккаунты" (внизу сайдбара) — переключает между: все, только онлайн, без группы, конкретная группа. Фильтрация применяется глобально ко всем страницам.
* Маскирование логинов — в Настройках можно включить/выключить отображение логинов звёздочками (как на скриншоте). Полезно для стримов и скриншотов.
* Рекомендация: перед массовыми операциями (продажа, CL, покупки) убедитесь что нужные аккаунты залогинены (статус "Онлайн"). Используйте группы для удобной организации — например, группа "CS2" для аккаунтов с CS2 инвентарём, "Фарм" для тех кто на фарме карточек.
* Контекстное меню работает и при множественном выделении — если выделить несколько аккаунтов (Ctrl+клик или Shift+клик), то пункты "Войти", "Выйти", "Обновить инфо" и другие массовые действия применятся ко всем выбранным.

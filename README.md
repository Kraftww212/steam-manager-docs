# Всем QQ

Steam Manager — софт для работы с большим количеством Steam-аккаунтов из одного окна: вход, инвентари, торговая площадка, трейды, покупки, фарм карточек, прогрев по расписанию. Поддержка и развитие лежат на моих плечах. Если вам нравится, что я делаю, порекомендуйте софт знакомым.

Для запуска нужен лицензионный ключ: софт открывается только после активации. Ключ выдаётся в нашем боте, там же продление. Есть тарифы Standard и Premium: Premium открывает расширенные функции (Prime, FloatDB, хранилища, крафт и другие).

### Быстрый старт

1. Установите софт и активируйте ключ (при первом запуске откроется окно активации, доступны серверы Европа и Россия).
2. Зайдите в **Настройки** и выставьте число потоков под ваш объём аккаунтов и прокси.
3. Добавьте прокси в **Настройки → Прокси**, сделайте авто-привязку.
4. Импортируйте аккаунты (TXT или maFile) на вкладке **Аккаунты** и нажмите **Войти во все**.
5. Дальше — инвентарь, маркет, Prime, фарм и расписание по вкладкам ниже.

{% hint style="info" %}
Перед массовыми операциями проверьте всё на 2–3 аккаунтах: так вы подберёте настройки потоков и не поймаете лимиты Steam.
{% endhint %}

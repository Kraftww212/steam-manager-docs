# Все функции

### 1. Аккаунт

* Добавление аккаунтов (вручную, импорт TXT, импорт maFile, привязка maFiles из папки или ZIP)
* Удаление аккаунтов (одного / нескольких, с подтверждением)
* Логин / Логаут (один, несколько, все), «Стоп» для массового входа
* Открытие встроенного браузера по аккаунту (с расширениями)
* Генерация 2FA кода из shared secret
* Обновление информации аккаунтов (refresh info): баланс, холд, ТП, Prime, лимит, VAC, стоимость инвентаря
* Группировка аккаунтов (CRUD групп, назначение аккаунтов в группы, глобальный фильтр по группе)
* Экспорт аккаунтов (TXT с настраиваемыми полями и разделителем, ZIP с maFiles)
* Копирование данных из контекстного меню (login:pass, 2FA, SteamID и т.д.)
* Команды между аккаунтами (принять трейд, отправить трейд, добавить/удалить друга)

***

### 2. Профиль Steam

* Изменение аватарки / установка случайной из встроенного набора (CL quest 115)
* Изменение настроек приватности (open / friends\_only / close / comment\_close)
* Установка фона из инвентаря (CL quest 126)
* Крафт значка профиля (CL quest 124)
* Установка избранного значка (CL quest 127)
* Установка реального имени в профиле (CL quest 111)
* Установка статуса в Steam (CL quest 117)

***

* Добавление игр в избранное / вишлист (quest 108)
* Комментарий к скриншоту (quest 109)
* Установка реального имени (quest 111)
* Заход в игру / idle (quest 112)
* Добавление в друзья (quest 113)
* Голосование за айтем в мастерской (quest 114)
* Установка аватара (quest 115)
* Установка статуса (quest 117)
* Лайк активности друзей (quest 118)
* Подписка на предмет мастерской (quest 119)
* Покупка на маркете (quest 120)
* Overlay / лайк гайда (quest 121)
* Трейд с друзьями (quest 122)
* Просмотр топиков / поиск на форуме (quest 123)

***

### 4. Торговая площадка (Маркет)

* Просмотр стакана ордеров (orderbook) по ссылке
* Создание ордера на покупку (buy order), режимы «фикс. количество» и «на весь баланс»
* Отмена ордера на покупку
* Продажа предметов (один / массовая), 4 стратегии цены: Мин -1, Автобай, Стакан, Своя цена
* Снятие лотов с продажи (один / несколько)
* Перевыставление лотов (relist) по новой цене покупателя
* Просмотр своих лотов (my listings)
* Проверка цен (getPrices) с кешем и ротацией прокси
* Закладки предметов маркета (добавить / удалить / список)
* Проверка доступа к маркету (market eligibility), авто-пометка аккаунтов с закрытой ТП
* Разблокировка маркета (покупка Game Item)
* Автоподтверждение листингов через Steam Guard
* Автопродажа инвентаря (по играм и стратегии)
* Мобильные подтверждения (список, принять/отклонить, массово)

***

### 5. Инвентарь

* Просмотр инвентаря по играм (CS2, TF2, Steam, Dota 2, Rust и кастомные)
* Массовая загрузка инвентаря
* Просмотр всех предметов (агрегация по аккаунтам, по валютам)
* Оценка стоимости инвентаря
* Наборы карточек (card sets) — загрузка, кросс-аккаунт сборка, отправка, автокрафт значков
* Крафт значков из карточек
* FloatDB скан (float value, seed, ранги) и продажа прямо из таблицы
* Хранилища CS2 (Storage Units): депозит и вывод
* Крафт предметов CS2 (Trade Up), StatTrak отдельно от обычных

***

### 6. Трейд

* Отправка трейда (аккаунту / по trade URL), большие партии режутся по 200 предметов на оффер
* Распределение предметов между аккаунтами / возможность задавать количество
* Просмотр входящих/исходящих офферов
* Принятие / отклонение / отмена оффера
* Лутинг — массовый забор предметов с N аккаунтов на получателя

***

### 7. Покупки

* Покупка игры по Sub/Package ID
* Покупка бандла (Bundle)
* Добавление бесплатных игр (Free Licence) — как в ASF, плавающий блок Free Games
* Просмотр информации о пакете перед покупкой (превью)
* Получение цены игры через корзину
* Активация гифт-кодов / wallet-кодов (массово, с задержками и ретраями, история)
* Добавление лицензий (app/sub) массово
* Подтверждение перед платными покупками, защита от повторной покупки при обрыве связи

***

### 8. «Prime»

* Раскид предметов с источника по получателям (вручную, по конфигу, автоподбор)
* Режимы: раскид → продажа → покупка игры, или только раскид
* Конфигурации предметов/стратегий (сохранение/загрузка)
* Статус-таблица текущих пайплайнов, фильтр «без Prime»
* История пайплайнов с действиями: перевыставить, проверить баланс, купить

***

### 9. Фарм

* Фарм карточек (Card Farm) — старт/стоп по аккаунтам, автологин офлайн-аккаунтов, стратегии «набор часов» и «активный», просмотр прогресса по играм
* TF2 фарм предметов — GC-подключение, idle, получение дропов, расширитель рюкзака

***

### 10. Расписание

* Создание задач-цепочек прогрева (просмотры, idle, комментарии, лайки, вишлист, группы)
* Типы расписаний: ежедневно, таймер, дни недели, случайно раз в неделю
* Опции задачи: потоки, ретраи, стоп при ошибке, паузы между шагами, авто-вход/выход, пропуск играющих аккаунтов
* Включение / выключение задач, запуск вручную сразу (run now)
* Шаблоны задач (сохранение / применение / удаление) и готовые рецепты прогрева
* История запусков с результатом по каждому шагу

***

### 11. Прокси

* Добавление / удаление / редактирование прокси
* Массовый импорт прокси (текст, дубликаты пропускаются)
* Назначение прокси на аккаунты (вручную / авто, равномерно)
* Сброс назначений
* Ротация прокси и refresh-ссылки (настройка в Settings)

***

### 12. Пополнение

* Проверка API-ключа внешнего сервиса
* Массовое пополнение баланса Steam
* Проверка статуса транзакции

***

### 13. Настройки и системное

* Язык (RU/EN)
* Лимиты одновременных логинов, задержки, ретраи
* Авто-relogin, авто-refresh при входе, автозагрузка инвентаря и сетов при входе
* Подарочные трейды, invisible/online статус
* OS-уведомления
* Маскирование логинов
* Тема (тёмная/светлая, акцентный цвет)
* Мониторинг трафика (таблица по категориям, сброс)
* Экспорт / импорт всех настроек (без паролей аккаунтов)
* Управление расширениями (установка, удаление, вкл/выкл, обновление)
* Лицензия (активация, выбор сервера, пинг)
* Курсы валют (автообновление)
* Панель логов (фильтры: Все / Продажа / CL и цепочки)
* Оповещения о Free Games (плавающий блок, раздача с подтверждением)
* Обновление приложения (скачать, установить, пропустить)

***

### 14. Чекер

* Полная проверка аккаунта (баланс, лицензии, баны, Steam Guard и т.д.)
* Резолв названий игр
* Оценка стоимости инвентаря
* Проверка статуса маркета

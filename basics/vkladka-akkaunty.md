# Вкладка "Аккаунты"

## 1. Главная страничка

<figure><img src="https://890104280-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgYLkm2P4moGZ7LimV51r%2Fuploads%2FtcN5MWDmQhLEAaqtRr7K%2Fimage.png?alt=media&amp;token=5bdd0b5a-2556-4ef8-8cfb-c7c6cb40cbc4" alt=""><figcaption></figcaption></figure>

1\. Войти во все — массовый логин всех аккаунтов в базе. Запускает параллельный вход (количество потоков настраивается в Настройках). Аккаунты авторизуются в Steam, получают куки сессии и становятся доступны для всех операций. Кнопка работает и после «Стоп».

2\. Выйти из всех — массовый логаут всех онлайн-аккаунтов. Закрывает сессии Steam.

3\. Стоп (красная кнопка) — экстренная остановка всех текущих операций: логинов, продаж, покупок, CL-заданий и других массовых действий.

4\. Импорт — загрузка аккаунтов в базу. Поддерживает: TXT-файл (`login:password`, `login:password:shared_secret:identity_secret` и другие варианты, разделитель определяется по каждой строке), maFile-файлы, а также привязку maFiles из папки или ZIP к уже существующим аккаунтам. Если файл не прочитался — покажет ошибку, а не «0 ошибок».

<figure><img src="https://890104280-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgYLkm2P4moGZ7LimV51r%2Fuploads%2F1TE7AnN7zCREF2vL8lrA%2Fimage.png?alt=media&amp;token=84eca0d8-09d6-42d2-83b4-c24a3ede74fa" alt=""><figcaption></figcaption></figure>

5\. Добавить — ручное добавление одного аккаунта: логин, пароль, shared\_secret и другие данные. Логин должен быть уникальным, дубликат отклоняется с сообщением.

6\. Группы — управление группами аккаунтов: именованные группы с цветными метками, добавление/удаление аккаунтов. Число в скобках — количество групп. Используется для фильтрации и массовых действий над выбранной группой.

7\. Колонки — настройка видимых столбцов таблицы. Можно скрыть/показать: номер, аватар, логин, статус, баланс, холд, стоимость CS2 инвентаря, количество предметов, лог, 2FA, прокси и другие. Выбор сохраняется.

8\. Обновить — запускает refresh info для выбранных или всех аккаунтов: баланс, статус кошелька, ТП, VAC, Prime, стоимость инвентаря. При массовом обновлении запросы идут не более чем по три параллельно.

9\. Баг фича

10\. Статистика в шапке — "Онлайн: 2, Пул: 0/0, Всего: 973". Быстрый обзор: сколько аккаунтов онлайн, состояние пула параллельных сессий, общее количество.

11\. Поиск по логину — фильтрация таблицы по имени аккаунта, частичный поиск. `Ctrl+F` ставит фокус.

12\. Таблица аккаунтов — основная область. Столбцы:

* \# — порядковый номер (перетаскивание строк меняет порядок)
* Аватар — иконка Steam-профиля
* Логин — имя аккаунта (маскируется звёздочками, если включено в Настройках)
* Статус — Оффлайн / Онлайн / Ошибка (при наведении текст ошибки) / вход…
* Баланс — баланс кошелька Steam в валюте аккаунта
* Холд — холд баланс (если есть)
* CS2 Инв. — стоимость CS2 инвентаря
* Предметов — сколько предметов загружено в базу
* Лог — последнее событие аккаунта
* 2FA — наличие привязанного Steam Guard (+ = привязан)
* Прокси — назначенный прокси-сервер

### 2. Контекстное меню (ПКМ по строке)

Открывает расширенное меню: логин/логаут, редактирование, открыть инвентарь, запустить чекер, CL-прогресс, мобильные подтверждения, трейды, встроенный браузер Steam, копирование данных (login:pass, SteamID, 2FA-код, shared\_secret и др.), логи, генерация 2FA-кода, создание команды другому аккаунту, удаление. При множественном выделении массовые пункты применяются ко всем выбранным.

*Выйти* — разлогинивает выбранный аккаунт. Статус меняется на "Оффлайн". Если аккаунт уже оффлайн — пункт будет "Войти".

*Редактировать* — модальное окно с полями аккаунта: логин, пароль, shared\_secret, identity\_secret, email, прокси, trade URL и другие. Здесь же можно изменить данные авторизации.

***

### 2.1 Инвентарь

Открывает модальное окно с полным инвентарём аккаунта. Показывает предметы по играм (CS2, TF2, Steam, Dota 2 и др.) и их рыночную стоимость. Отсюда можно продать предметы на маркет или выбрать для трейда.

<figure><img src="https://890104280-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgYLkm2P4moGZ7LimV51r%2Fuploads%2FH91OgQzLg4gAkUuVsSS6%2Fimage.png?alt=media&amp;token=8d8b28bc-d574-404b-b525-a73859779c75" alt=""><figcaption></figcaption></figure>

Вкладки справа: Инвентарь / Сеты / Мои лоты:

* Инвентарь — предметы в инвентаре аккаунта
* Сеты — наборы карточек Steam для крафта значков: полные и неполные сеты, отправка карточек между аккаунтами, просмотр уже скрафченных значков
* Мои лоты — предметы, выставленные на продажу. Можно снять лоты или перевыставить по новой цене

Выбор игры: CS2 / TF2 / Steam / Dota 2 / Rust / +. Кнопка "+" добавляет кастомную игру по App ID и Context ID.

Кнопки: Загрузить (с серверов Steam), Загрузить цены (рыночные цены предметов), Сканировать флоаты (float value и ранг FloatDB для CS2). Фильтры: поиск, скрыть not tradable, скрыть trade ban, стакать одинаковые предметы.

### 2.2 Чекер

<figure><img src="https://890104280-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgYLkm2P4moGZ7LimV51r%2Fuploads%2FeKtpkAM5zccBV47wK7jm%2Fimage.png?alt=media&amp;token=bc7dc71b-86e8-4adc-9243-e07c62beb4e5" alt=""><figcaption></figcaption></figure>

Запускает полную проверку аккаунта: баланс кошелька, список лицензий/игр, VAC/Trade баны, статус Steam Guard, ограничения маркета. Если проверка не удалась (нет сессии, ошибка сети) — покажет текст ошибки, а не пустые значения и ложные «false».

* Обновлено — дата и время последней проверки
* Страна — определяется по кошельку
* SteamID — Steam ID64 аккаунта

**Кошелёк:** Баланс и В холде в валюте аккаунта.

**Ограничения** (зелёная рамка = чисто, красная = проблема): VAC, Community Ban, Locked, Limited, Trade Ban, Маркет.

**Стоимость инвентаря:** чекбоксы CS2 / Dota 2 / Rust / Steam и кнопка «Оценить инвентарь» — загрузка и расчёт стоимости по ценам маркета.

**Игры / Лицензии:** количество игр и лицензий, поиск по названию или appid, таблица игр (App ID, название, тип).

***

### 2.3 CL прогресс

Модальное окно "Community Leader" — прогресс выполнения заданий значка для конкретного аккаунта.

* Выполнить все — запускает автоматическое выполнение всех незавершённых заданий (со статусом "Todo")
* Обновить — загружает актуальный прогресс с серверов Steam
* Прогресс — круговая диаграмма и счётчик (например, 23 / 28 выполнено)
* Список заданий — зелёная галочка "Done" = выполнено, жёлтый "Todo" = не пройдено
* Debug: Steam API response — сырой ответ Steam API для диагностики

***

### 2.4 Подтверждения действий в Steam

Аналог мобильного Steam Guard — показывает ожидающие мобильные подтверждения: продажа на маркете, трейд, покупка на маркете. Кнопки Принять / Отклонить по каждому и Принять все.

Для работы нужен привязанный `identity_secret` (из maFile). При массовой продаже софт подтверждает листинги автоматически — и только листинги маркета, чужие трейды и другие подтверждения не трогает.

***

### 2.5 Трейд-офферы

Все обмены аккаунта. Вкладки Входящие / Исходящие. Для входящих — Принять / Отклонить, для исходящих — Отменить. Показываются участник, предметы и статус оффера.

***

### 2.6 Встроенный браузер

Запускает встроенный Chromium с автоматически авторизованной сессией аккаунта — вы сразу залогинены в Steam Community и Store без ввода логина/пароля/2FA. Софт берёт куки активной сессии, ставит их в окно и открывает Steam Community. Поддерживает установленные расширения.

Советы:

* Браузер работает только для онлайн-аккаунтов
* Каждое окно открывается отдельно — можно открыть несколько аккаунтов параллельно
* Если сессия истекла — перелогиньте аккаунт и откройте заново

## Полезные советы

* Перетаскивание строк — зажмите строку и перетащите для изменения порядка.
* Двойной клик по строке — открывает редактирование аккаунта.
* Групповой фильтр (внизу сайдбара) — все / только онлайн / без группы / конкретная группа — применяется глобально ко всем страницам.
* Маскирование логинов — в Настройках, полезно для стримов и скриншотов.
* Перед массовыми операциями убедитесь, что нужные аккаунты залогинены. Используйте группы для организации.

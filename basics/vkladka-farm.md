# Вкладка "Фарм"

## Страница «Фарм»

Автоматический фарм коллекционных карточек Steam и предметов TF2. Два режима работы: Карточки и TF2.

***

#### Переключатель режимов (вверху)

* 🃏 Карточки — фарм карточек Steam через idle в играх
* ⚡ TF2 (скриншот 2) — фарм предметов TF2 через Game Coordinator

***

| Блок                  | Описание                                                            |
| --------------------- | ------------------------------------------------------------------- |
| Игр с карточками: 11  | Сколько игр в библиотеках аккаунтов имеют оставшиеся дропы карточек |

#### Фильтры и кнопки

* Выпадающий список — фильтр: `С карточками`, все, без карточек. Если ни у кого нет карточек, софт сам переключит на «Все аккаунты» и подскажет
* Поиск по логину — текстовое поле для поиска аккаунта
* Все (10) — выбрать все аккаунты
* × Снять — снять выделение со всех
* ↻ Обновить — обновить информацию о бейджах и оставшихся дропах (у онлайн-аккаунтов)
* ▶ Старт (0) (зелёная) — запустить фарм на выбранных аккаунтах. Оффлайн-аккаунты софт залогинит сам, число одновременных входов — из настроек. После запуска показывается сводка: сколько запущено, сколько с ошибкой и почему
* ⏹ Стоп (красная) — остановить фарм, игра закрывается сразу; аккаунты, ждавшие в очереди на запуск, тоже снимаются

#### Таблица аккаунтов

| Столбец       | Описание                                                              |
| ------------- | --------------------------------------------------------------------- |
| ☐             | Чекбокс выбора аккаунта                                               |
| Аккаунт       | Логин аккаунта                                                        |
| Статус        | `offline` / `online` / `вход…`                                        |
| Стратегия     | Что делает фарм сейчас: `idle` — нечего фармить, `⏰ набор часов` — везде меньше 3 часов, играем все игры сразу, `🎯 активный` — есть игра с 3+ часами, крутим её циклом «играть/пауза», `✅ завершён` — все карточки выпали, `⚠ ошибка` |
| Текущая игра  | Какая игра сейчас фармится (`—` если не активен)                      |
| Игр           | Количество игр с оставшимися дропами                                  |
| Карт остаётся | Сколько карточек осталось выфармить                                   |
| Сфармлено     | Сколько карточек выпало в текущей сессии / за всё время               |
| Действия      | Кнопки управления для каждого аккаунта                                |

#### Кнопки действий (для каждого аккаунта)

* ▶ (зелёная) — запустить фарм на этом аккаунте
* ↻ — обновить информацию о бейджах
* 📋 — подробности (список игр, часы, оставшиеся дропы, сфармлено по игре)

#### Как работает

1. Софт читает страницу значков аккаунта и узнаёт, в каких играх ещё падают карточки и сколько часов наиграно.
2. Пока ни в одной игре нет 3 часов, включаются все игры с карточками одновременно (набор часов). Как только у игры набирается 3+ часа, фарм переключается на неё одну и крутит цикл «играть → короткая пауза», так карточки падают быстрее.
3. Каждый дроп ловится сразу, страница значков перечитывается, счётчики обновляются. Плановое обновление — раз в 5 минут при наборе часов и раз в 15 минут в активном фарме.
4. Если аккаунт перелогинился (вручную или авто ре-логин), фарм подхватывает новую сессию и снова запускает игру.
5. После падения или закрытия приложения фарм не продолжается сам: запустите его заново.

{% hint style="info" %}
Для фарма нужен статус online в настройках («Режим входа в сеть»). Пока аккаунт фармит, не запускайте на нём игру с другого устройства: Steam прервёт idle.
{% endhint %}

### Режим «TF2»

Фарм предметов TF2 через подключение к Game Coordinator (GC).

#### Статистика (верхние блоки)

| Блок                  | Описание                                        |
| --------------------- | ----------------------------------------------- |
| Онлайн: 1             | Количество онлайн-аккаунтов                     |
| Активно: 0            | Сколько аккаунтов сейчас фармят TF2             |
| GC подключен: 0       | Сколько аккаунтов подключены к Game Coordinator |
| Предметов (сессия): 0 | Сколько предметов выпало за текущую сессию      |

#### Кнопки управления

* Все (1) — выбрать все аккаунты
* × Снять — снять выделение
* ↻ Обновить — обновить статусы GC и дропов
* ▶ Старт (0) (зелёная) — запустить TF2-фарм на выбранных аккаунтах
* ⏹ Стоп (красная) — остановить фарм

#### Таблица аккаунтов

| Столбец  | Описание                                                |
| -------- | ------------------------------------------------------- |
| Аккаунт  | Логин                                                   |
| Статус   | Статус: `idle` — ожидает, `farming` — фармит, `offline` |
| GC       | Статус подключения к Game Coordinator                   |
| Рюкзак   | Слоты рюкзака, занято, число расширителей               |
| Предметы | Количество полученных предметов и список последних дропов |
| Время    | Сколько времени фармит                                  |

#### Как работает TF2 фарм

TF2 имеет еженедельный лимит дропов — 1-2 кейса в неделю. Софт держит аккаунт «в игре» через GC и записывает каждый полученный предмет. Если рюкзак заполнен, дропы не приходят: расширитель рюкзака можно купить прямо из этой вкладки через магазин Steam (покупка идёт через веб-оформление заказа с подтверждением).

### Страница «Community Leader»

Модуль автоматического выполнения заданий для получения значка Community Leader в Steam. Выполняет все необходимые действия на аккаунтах параллельно (число потоков из настроек).

***

#### Панель управления (верхняя строка)

* Запустить все (0) — запустить выполнение всех заданий на выбранных аккаунтах. Число в скобках — количество выбранных аккаунтов
* Стоп (красная) — остановить выполнение: останавливаются и уже идущие аккаунты, и те, что ждали в очереди
* Обновить — обновить статус заданий с серверов Steam
* Скрыть настройки — свернуть блок настроек CL

#### Настройки CL

**Game AppID**

Игра для выполнения заданий, связанных с инвентарём и картами. По умолчанию `440` (TF2). Подсказка показывает популярные варианты: `440 = TF2, 730 = CS2, 570 = Dota 2`. Если у аккаунта нет этой игры, софт подбирает игру из библиотеки сам, у каждого аккаунта своя.

**Откуда берём сет карт для крафта**

Два варианта:

* Получить сет трейдом с аккаунта-донора — карты отправляются трейдом с другого аккаунта. Цепочка: `Трейд → Крафт → Фон → Покупка 1 предмета на маркете`
* Купить сет карт на маркете — карты покупаются с торговой площадки. Цепочка: `Покупка сета → Крафт → Фон → Трейд 1 предмета соседу`

**Аккаунт-донор**

Выпадающий список: `Авто (ближайший онлайн)` — донор не назначается, аккаунты работают парами: сосед по списку присылает предмет для задания Trade, и наоборот. При нечётном числе аккаунтов последний просто отправляет трейд первому. Если выбрать конкретный донор, он раздаёт наборы карт всем остальным.

**Покупка на маркете (URL предмета)**

Ссылка на предмет для выполнения задания "Buy on Market". По умолчанию — карточка CS2 Anarchist

#### Список аккаунтов

* Все (1) — чекбокс для выбора всех аккаунтов
* Для каждого аккаунта показан:
  * Чекбокс выбора
  * Имя аккаунта
  * Прогресс-бар (`27/28` — выполнено заданий из общего числа), обновляется по ходу выполнения
  * Процент выполнения в круге

#### Сетка заданий

Все 28 заданий Community Leader отображаются в два столбца. Для каждого задания:

* Иконка статуса:
  * ✅ (зелёный круг) — задание выполнено
  * 🔢 (число в круге, например `14`) — задание в процессе или требует повтора
* Название задания — на английском, как в Steam
* OK (зелёная кнопка) — задание выполнено. Можно нажать для ручного повторного запуска
* — (красная кнопка) — задание не выполнено или произошла ошибка

#### Как идёт выполнение

* Сначала софт читает прогресс значка с серверов Steam и делает только невыполненные задания. Если прогресс получить не удалось, аккаунт останавливается с ошибкой, а не выполняет всё заново.
* У каждого задания свой таймаут (idle в игре — до 35 минут, покупка набора карт — 15 минут, трейды — 20 минут). Задания, которые тратят деньги или отправляют трейды, при таймауте повторно не запускаются.
* После основного прохода выполняется ещё два контрольных прохода по тому, что не засчиталось.
* Ход выполнения виден в панели логов (вкладка «CL / Цепочки») и в ленте на Обзоре.

#### Кнопки внизу справа

* Run All — запустить все невыполненные задания
* Reload — обновить статус заданий

#### Debug

`Debug: Steam API response` — сворачиваемый блок с отладочной информацией ответов Steam API

{% hint style="warning" %}
Для трейдов и покупок на аккаунтах нужен `identity_secret`, для покупки набора карт — деньги на балансе. Аккаунт с закрытой ТП задание «Buy on Market» выполнить не сможет.
{% endhint %}
